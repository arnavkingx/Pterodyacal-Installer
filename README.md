# APNELY Pterodactyl Installer

Made by Arnav Sharma.

## Files
- `install.sh` — main launcher/menu
- `panel.sh` — Pterodactyl Panel installer
- `wings.sh` — Wings installer/manager
- `nginx.sh` — Nginx manager
- `ssl.sh` — Certbot/SSL manager

## GitHub
Keep all files in the repository root. The default one-command installer is:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/arnavkingx/Pterodyacal-Installer/main/install.sh)
```

Make shell files executable in GitHub if desired; `install.sh` can also invoke them with `bash`.
